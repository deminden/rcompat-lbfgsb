# Line-search failure and restoration oracle

Six public `stats::optim(method="L-BFGS-B")` calls generated by
`scripts/generate_line_search_fixtures.R` with R 4.6.1 on macOS ARM. The artifact
records the generator SHA256, session, platform, BLAS path and one-thread setting.
Generation rereads every numerical field and requires binary64 byte round trips
before replacing the file. No optimizer source is an implementation input.

The independent objectives cover:

- A quadratic with an intentionally reversed gradient: twenty unsuccessful
  trials and abnormal termination, returning the initial point and value.
- Absolute distance to 0.12345: a narrow-bracket warning revisits the best trial
  after rejecting another point. A zero iteration budget returns that accepted
  iterate with `NEW_X`; its constant-magnitude slope cannot satisfy curvature.
- A quadratic with an intentionally inconsistent piecewise gradient: one
  accepted step creates history, then two failed searches exhaust their budgets,
  with exactly one memory reset. The output retains the accepted point and value.

Each runs with finite and infinite bounds. The inconsistent-gradient cases are
recovery tests, not claims that such callbacks define valid optimization models.
The full result and every raw callback parameter are checked bit for bit under
`ArithmeticProfile::R461MacArm`. The latter two failure cases caught a widened
retry-warning rule that could incorrectly accept a rounded zero-length step.

Generate explicitly with an appropriate R environment:

```sh
OPENBLAS_NUM_THREADS=1 Rscript scripts/generate_line_search_fixtures.R
```

Verify from a clean checkout without R:

```sh
python3 scripts/verify_oracles.py
python3 scripts/test_verify_oracles.py
cargo test --test line_search_oracles
```

The verifier pins the payload SHA256 as well as the recipe fingerprint. An
intentional regeneration requires review and an updated payload fingerprint.
The recorded reference is evidence for this arithmetic profile, not a promise
that all callbacks reproduce every host math library's behavior.
